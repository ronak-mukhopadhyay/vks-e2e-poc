# vks-e2e-poc
Guide to deploy your first VKS cluster, set up a jumpbox to interact with your k8s environment, stand up platform components that help build, release, and run modern applications

Assumes that supervisor is already enabled 

Outline: 
1. Deploy VKS cluster
2. Deploy jumpbox
3. install VCF cli + plugins on jumpbox
4. connect to VKS cluster
5. deploy lightweight test application
6. deploy & configure Harbor
7. push image to Harbor
8. deploy application to VKS
9. (optional) Deploy AddOn(s) - Headlamp, Prometheus, Telegraf
